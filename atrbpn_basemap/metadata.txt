description=Adds ATR/BPN (Indonesia) Peta Dasar aerial imagery as an XYZ basemap and keeps its tile URL up to date automatically.
about=Independent INDO-GO GeoSpatial derivative of ATR BPN Basemap 1.1.3 by Fadli Arya Wisnu Baradi (GPL-2.0-or-later). Report issues via this project's GitHub; metadata email is the original author's, not derivative support.
    The plugin reads the map scripts of the ATR/BPN Peta Dasar website (petadasar.atrbpn.go.id) to find the latest aerial imagery tile URL, tests a sample tile, then updates layers in the current project and the XYZ connection in the Browser panel. The tile session token is refreshed automatically in the background. Imagery for a selected extent can also be exported to GeoTIFF.
    Limitations: coverage is limited to areas of Indonesia available in ATR/BPN Peta Dasar, and an internet connection is required. Data availability depends entirely on the ATR/BPN service.
    This plugin is developed independently and is not affiliated with the Ministry of Agrarian Affairs and Spatial Planning/National Land Agency (ATR/BPN). The imagery remains the property of ATR/BPN; please follow the provider's terms of use.

    - Independent branding preview based on ATR BPN Basemap 1.1.3; no new imagery access features. Not released or security-certified.

    1.1.2
    - Plugin description, about and changelog are now in English, as required by the QGIS plugin repository. No functional changes.
    1.1.1
    - Fix: since 25 November 2026 the ATR/BPN aerial tile URL contains a session token that changes every few minutes, so layers could go blank. The plugin now stores a URL template and refreshes the token automatically in the background (project layers, XYZ connection, and during GeoTIFF export).
    - Fix: URL detection is retried up to 3 times with a fresh token when the test tile does not respond.
    - config.json now supports a {token} placeholder in tile_url.
    1.1.0
    - New: remote configuration (config.json on GitHub). When the ATR/BPN website changes, the fallback tile URL can be updated without installing a new version.
    - New: message with a button to GitHub when the aerial imagery URL cannot be found.
    - New: notification when a newer plugin version is available.
    - Plugin version and GitHub link are shown in the About menu.
    1.0.1
    - Fix: adapted to changes on the ATR/BPN Peta Dasar website (November 2026). The aerial tile URL is now ?wms/{x}/{y}/{z}/2 and map scripts are read from the new map page.
    - Fix: the "ATR BPN Foto Udara" XYZ connection in the Browser panel is now saved correctly.
    1.0.0
    - First release: ATR/BPN aerial imagery XYZ basemap, automatic tile URL detection, XYZ connection in the Browser panel, GeoTIFF export.
